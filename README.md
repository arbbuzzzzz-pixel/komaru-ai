# KomaruAI

Локальный AI-лаунчер для GGUF-моделей. Запускай любую модель прямо на своём устройстве — без интернета, без подписок, без утечек данных.

## Что это

KomaruAI — это лёгкое приложение, которое позволяет:
- Загружать любые GGUF-модели (Llama, Mistral, Qwen, Gemma и другие)
- Общаться с ними офлайн, полностью на своём железе
- Сохранять единый характер KomaruAI независимо от выбранной модели

## Почему KomaruAI

- **Без интернета** — после загрузки модели всё работает офлайн
- **Любая модель** — выбирай ту, что подходит под твоё железо
- **Один характер** — каждая модель ведёт себя как KomaruAI
- **Приватность** — никакие данные не покидают твоё устройство

## Как начать

1. Скачай `.gguf` модель с [Hugging Face](https://huggingface.co/models?library=gguf)
2. Положи файл в папку `models/`
3. Запусти KomaruAI и выбери модель
4. Общайся

## Скоро

- Каталог моделей с рекомендациями под твоё железо
- Голосовой ввод и озвучка
- Работа с локальными файлами (RAG)
